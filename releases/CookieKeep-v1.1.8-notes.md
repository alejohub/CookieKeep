## CookieKeep v1.1.8

### Improvements

- Added **Ver cookies que se eliminarán** to dry-run, selected-range and global cleanup dialogs.
- Details show the exact candidates from the original preview, including cookie domain, name, path, session/persistent status, approximate size, store and CHIPS metadata. Cookie values are hidden.
- Return to the original summary without losing the operation, interval or preview token. Cleanup still revalidates current protection and preview authorization before deletion.
- Consolidated readable typography across popup, dashboard, tables and dialogs, with larger secondary text and preserved responsive layouts.

### Installation

Extract `CookieKeep-v1.1.8-chromium.zip`, enable Developer mode at `chrome://extensions` or `edge://extensions`, then choose **Load unpacked** and select the extracted folder containing `manifest.json`.
