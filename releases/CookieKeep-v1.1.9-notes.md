## CookieKeep v1.1.9

### Improvements

- Increased functional text and controls across the popup and dashboard for better readability.
- Standardized the typography scale at 15px for body text and controls, 14px for secondary/help/table text, and 13px for discreet version/GitHub metadata.
- Improved button and select proportions while preserving compact layouts and existing title, section and metric sizes.
- Verified responsive wrapping without horizontal overflow in the popup, dashboard cards, filters and tables.

This release contains visual changes only; cleanup, protection, history, navigation and permissions are unchanged.
